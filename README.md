# Alien Prison Game Walkthrough Template

A reusable markdown template for writing walkthroughs for browser escape games, Roblox-style experiences, and small puzzle games.

Example/reference page: [Escape the Alien Prison](https://escapethealienprison.xyz/).

## Contents

- `walkthrough-template.md` — main walkthrough template.
- `code-status-template.md` — template for code/status pages.
- `verification-notes.md` — notes for checking iframe, platform, and Roblox-style verification pages.
