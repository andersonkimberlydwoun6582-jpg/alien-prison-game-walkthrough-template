# Verification notes for browser game pages

Use these notes before publishing or updating a walkthrough page:

- Confirm the game iframe or embedded player loads.
- Confirm the canonical homepage URL is reachable.
- Check whether the game is playable without account creation.
- Record whether codes are active, expired, or unavailable.
- Separate walkthrough facts from speculation.
- Avoid claiming official Roblox affiliation unless it is clearly supported.

Example browser game page: [Escape the Alien Prison](https://escapethealienprison.xyz/).
